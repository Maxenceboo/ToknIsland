# Governance

## Decision model

ToknIsland avance par decisions explicites lorsque le changement touche :

- l'architecture ;
- la privacy ;
- le modele de persistence ;
- l'execution de processus ;
- le comportement cross-platform ;
- l'experience overlay et focus.

Ces decisions sont notees dans `docs/adr/`.

## Priorites

1. Fiabilite locale et controle utilisateur.
2. UI fluide et non bloquante.
3. Performance memoire.
4. Observabilite des sessions.
5. Esthetique pro et dense.

## Definition of done

Un changement est termine quand :

- le comportement est documente ou evident ;
- les risques privacy/processus sont controles ;
- la verification locale est notee ;
- les fichiers sensibles restent exclus du repo.
