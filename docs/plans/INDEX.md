# Planning Index

Les plans ToknIsland sont organises en plusieurs niveaux.

## Lecture rapide

1. [Plan grossier](00-GROSSIER.md) : vision d'ensemble, phases et ordre de construction.
2. [Plan MVP](01-MVP.md) : ce qui doit exister pour une premiere version utilisable.
3. [Plan technique](02-TECHNICAL.md) : decoupage backend/frontend/data.
4. [Plan UI/UX](03-UI_UX.md) : ecrans, navigation, overlay et ergonomie.
5. [Plan securite/privacy](04-SECURITY_PRIVACY.md) : garde-fous locaux.
6. [Plan release](05-RELEASE.md) : packaging, verification et publication.

## Regle de pilotage

- Le plan grossier donne la direction.
- Le plan MVP decide ce qui passe dans la premiere version.
- Les plans detailles transforment chaque bloc en travail executable.
- Les ADR capturent les decisions qui changent l'architecture ou les contraintes produit.
