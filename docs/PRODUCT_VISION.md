# Product Vision

ToknIsland aide les developpeurs a piloter plusieurs agents IA locaux depuis une app desktop rapide, lisible et respectueuse de la vie privee.

## Utilisateur cible

Developpeur ou createur technique qui travaille dans un IDE et veut :

- lancer des agents CLI sans perdre le contexte ;
- suivre les sessions longues ;
- reprendre une conversation interrompue ;
- comprendre les couts et volumes de tokens ;
- ouvrir rapidement les fichiers touches dans l'IDE.

## Promesse

Un cockpit local pour agents IA : pas un SaaS, pas un tableau de bord lourd, mais une interface native qui reste proche du code et de la machine.

## Contraintes produit

- Demarrage rapide.
- UI fluide pendant les sorties longues.
- Memoire cible inferieure a 80 Mo.
- Donnees locales par defaut.
- Overlay utile sans voler le focus clavier.
